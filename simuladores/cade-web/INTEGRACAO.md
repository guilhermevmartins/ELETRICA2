# CADe Web no laboratório

Cópia da aplicação `CLONE-FLUID/cade-web/dist`, integrada em Comandos elétricos.
O portal abre `index.php#cade-web`. Os arquivos deste diretório são estáticos e
devem ser publicados junto com o restante do site, preservando os caminhos.
O servidor precisa servir `.mjs` como JavaScript (`text/javascript`).

O editor salva automaticamente neste navegador, com chave própria do laboratório.
Use Salvar/Abrir para transferir os projetos JSON entre computadores; eles não
são enviados ao banco de dados. Arquivos CAD do programa original não são aceitos.

Adaptações locais: cabeçalho SENAI, tela cheia, dimensionamento da aba, chave de
armazenamento e suspensão do relógio da simulação quando a aba fica inativa.
O editor mantém seus símbolos e as limitações descritas na ajuda original.
Não é uma versão oficial do CADe_SIMU.
